System Architecture & Mathematical Specifications

Computer Vision Pipeline

  • Vector Geometry: Calculates 3D relative joint angles using spatial dot product: theta = arccos((v1 . v2) / (|v1| * |v2|))
  • Temporal Noise Reduction: Exponential Moving Average filter: S_t = alpha * Y_t + (1 - alpha) * S_{t-1} ($\alpha = 0.35$).
  • Angular Derivatives: Computes instantaneous kinetic velocity $\omega = \frac{d\theta}{dt}$.
  • Spatial ROI Clamping: Dynamic bounding box derivation from landmark extrema.

Deep Learning Core

  • Pose Landmark Net: BlazePose architecture predicting 33 spatial landmarks with depth.
  • Temporal Sequence Analysis: Sliding window classifier for posture state detection.
  • Loss Functions: Wing Loss coordinate regression + Categorical Cross-Entropy.
  • Performance: PCK@0.2 = 96.8%, Mean Latency = 12.5ms.
